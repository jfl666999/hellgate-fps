# HELLGATE

一个单文件的第一人称射击游戏，用原生 JavaScript + Canvas 2D 实现，零依赖、零构建、离线可玩。

## 运行

直接用浏览器打开 `index.html`，或者起一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

需要支持 Pointer Lock API 的现代浏览器（Chrome / Edge / Firefox / Safari）。

## 操作

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` | 移动 |
| `Shift` | 冲刺 |
| 鼠标 | 转向（点击开始后锁定指针） |
| 左键 | 射击（可长按连发） |
| `R` | 换弹 |
| `ESC` | 暂停 / 恢复 |

消灭地图上全部敌人即通关。

## 实现要点

- **光线投射渲染**：DDA 算法逐列扫描墙体，按垂直投影距离绘制带高度衰减的墙条，72° 水平视场。
- **深度缓冲精灵遮挡**：每列墙体距离写入 Z-buffer，敌人精灵逐列比对深度后合并可见区间再绘制，实现被墙正确遮挡。
- **程序化纹理**：砖墙与金属面板纹理由 Canvas 绘制并叠加噪声，预生成 4 档阴影层级用于距离雾化，避免运行时逐像素计算。
- **程序化音效**：枪声、换弹、命中、受伤等音效全部由 WebAudio 用噪声缓冲 + 滤波器 + 振荡器实时合成，不加载任何音频文件。
- **敌人 AI**：视线检测（LOS）唤醒、直线追踪 + 轴分离避障、邻近个体间排斥力避免重叠堆叠。

## 说明

项目为单文件形式，全部资源在运行时生成，因此没有 `package.json`、锁文件或静态资源目录。
